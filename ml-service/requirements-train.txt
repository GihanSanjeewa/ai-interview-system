# Extra dependencies for FINE-TUNING ONLY. Install on the GPU box:
#     pip install -r requirements.txt -r requirements-train.txt
#
# torch is deliberately NOT pinned here. On Google Colab the preinstalled build
# already matches the driver's CUDA version; forcing a reinstall usually breaks
# bitsandbytes. Install torch from pytorch.org only on a self-managed GPU box.
#
# Tesla T4 notes (compute capability 7.5):
#   * fp16 only — bf16 is unsupported, so train_qlora.py always uses fp16.
#   * FlashAttention-2 needs Ampere or newer; the script uses sdpa instead.
#   * bitsandbytes has supported sm75 4-bit NF4 since 0.39; 0.43+ is what the
#     current peft/transformers integration expects.

# --- Evaluation metrics (training/evaluate_model.py) -------------------------
# BLEU/ROUGE/BERTScore have no single canonical formula, so the harness prefers
# the standard implementations below and records which backend produced each
# number. All three are pure-Python and cross-platform. Without them the harness
# still runs on its own builtin BLEU/ROUGE and labels the scores accordingly;
# BERTScore is the one metric with no honest fallback, so it is reported as null
# when bert-score is absent rather than approximated.
sacrebleu>=2.4               # corpus/sentence BLEU, mteval-v13a tokenisation
rouge-score>=0.1.2           # ROUGE-1/2/L F-measure with Porter stemming
bert-score>=0.3.13           # contextual-embedding P/R/F1; downloads an encoder on first use
